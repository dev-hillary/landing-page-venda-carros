# Landing Page de Venda de Carros

Landing page de venda de carros desenvolvida com HTML, CSS e JavaScript.

## Sobre o projeto

O projeto consiste em uma landing page para divulgação e venda de veículos. A página apresenta carros em destaque e possui um botão de Dark Mode, permitindo alternar entre o tema claro e o tema escuro.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Landing page de venda de carros;
- Apresentação de veículos em cards;
- Botão de Dark Mode;
- Alternância entre modo claro e modo escuro;
- Botões de interesse;
- Layout responsivo.

## Objetivo

Desenvolver uma landing page de venda de carros utilizando conceitos de HTML, CSS e JavaScript.

## Observação

Este é um projeto acadêmico. Os veículos e informações apresentados são demonstrativos.
